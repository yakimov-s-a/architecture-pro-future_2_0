# Технический радар

## Квадрант: Языки программирования и фреймворки

| Технология                                     | Статус | Комментарий                                                                                         |
|------------------------------------------------|--------|-----------------------------------------------------------------------------------------------------|
| Python (для ИИ-сервисов)                       | Adopt  | Уже используется в ИИ-домене; сохраняется как основной язык ML/AI-пайплайнов                        |
| Golang (финтех)                                | Adopt  | Уже используется в финтех-сервисах; подходит для событийных консьюмеров                             |
| Java (финтех)                                  | Adopt  | Существующая база финтех-сервисов; совместим с экосистемой Kafka / Flink                            |
| PowerBuilder                                   | Hold   | Легаси-интерфейс операторов; не развивается, замена — веб-интерфейс поверх портала самообслуживания |
| SQL (T-SQL, диалект DWH)                       | Hold   | Используется только в рамках антикоррупционного слоя к легаси DWH                                   |
| TypeScript / React (для нового клиентского UI) | Trial  | Кандидат для замены PowerBuilder-интерфейса оператора                                               |

## Квадрант: Платформы

| Технология                                               | Статус | Комментарий                                                                             |
|----------------------------------------------------------|--------|-----------------------------------------------------------------------------------------|
| Облачная инфраструктура (IaaS / PaaS, мультизональность) | Adopt  | Основа переезда из on-prem; отдельные среды на домен                                    |
| Terraform (IaC)                                          | Adopt  | Модульная структура на все окружения                                                    |
| Kubernetes                                               | Trial  | Кандидат для оркестрации доменных сервисов и потоковых обработчиков                     |
| Microsoft SQL Server 2008 (текущий DWH)                  | Hold   | Устаревшая версия БД (снята с поддержки), только для чтения через ACL на время миграции |
| Cloud Data Warehouse                                     | Trial  | Целевое хранилище для доменных потоковых витрин                                         |
| Apache Camel ESB                                         | Hold   | Используется только для совместимости через ACL                                         |
| Managed Kafka                                            | Adopt  | Основа событийной шины в целевой архитектуре                                            |
| Apache Flink                                             | Trial  | Для потоковых трансформаций в доменных витринах                                         |

## Квадрант: Данные и интеграции

| Технология / практика                            | Статус | Комментарий                                                                       |
|--------------------------------------------------|--------|-----------------------------------------------------------------------------------|
| Schema Registry (каталог схем)                   | Adopt  | Обязателен с первого этапа трансформации                                          |
| Data Catalog (метаданные, происхождение данных)  | Adopt  | Нужен для навигации по доменам в портале самообслуживания                         |
| DLQ  паттерн                                     | Adopt  | Стандарт обработки ошибок событий с пилота                                        |
| CDC  из легаси DWH                               | Trial  | Временный механизм извлечения данных из DWH на этапе миграции                     |
| Self-service BI / Semantic Layer                 | Adopt  | Требование бизнеса — конструктор отчетов для сотрудников                          |
| REST / SOAP синхронные point-to-point интеграции | Hold   | Заменяются событийными контрактами, кроме случаев, требующих строгой синхронности |

## Квадрант: Архитектурные паттерны и практики

| Паттерн                                                      | Статус | Комментарий                                                               |
|--------------------------------------------------------------|--------|---------------------------------------------------------------------------|
| Event-Driven Architecture                                    | Adopt  | Ядро целевой архитектуры                                                  |
| Domain-Driven Design / Bounded Contexts                      | Adopt  | Основа разделения на домены                                               |
| Anticorruption Layer (ACL)                                   | Adopt  | Обязателен для изоляции легаси DWH / Camel на время миграции              |
| Data Mesh                                                    | Trial  | Целевая операционная модель для доменных витрин, разворачивается поэтапно |
| Self-Service Data Portal                                     | Adopt  | Требование бизнеса — витрина данных без ограничения по числу направлений  |
| CQRS                                                         | Assess | Возможен для доменов с высокой нагрузкой на чтение                        |
| Saga                                                         | Trial  | Нужен для обеспечения целостность данных в сквозных бизнес-процессах      |
| Monolithic Shared Database (текущий паттерн DWH)             | Hold   | Прямо противоречит цели независимого развития доменов                     |
| API Gateway с централизованным RBAC                          | Adopt  | Требуется для организации доступа к порталу самообслуживания              |
| Zero Trust / Data Classification (для медданных и финданных) | Adopt  | Требование регуляторов для чувствительных данных                          |
